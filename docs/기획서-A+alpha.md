# 도쿄 산책 · 기획서 (3D 디오라마)

> 규빈 & 아내 · 2026.10.17–22 · 5박 6일  
> 상태: 본체 = 아이소메트릭 디오라마 · 1인칭 제외  
> 갱신: 2026-09-07

---

## 1. 한 줄 정의

**레퍼런스 사진처럼, 파스텔 아이소메트릭 3D 디오라마 위에서 일차 일정을 둘러보는 반응형 웹 여행 가이드.**

실측 구글맵이 본체는 아니다. **애니메이션·장난감 도시 느낌**이 본체이고, 실측은 미니맵·거리·Maps 링크로만 보조한다.

---

## 2. 목표 / 비목표

### 목표
- 일차별 스팟·동선을 **입체 디오라마**로 한눈에 보기
- 스팟 상세(시간·거리·메모·이동 via·먹기)
- 드래그 회전 · 핀 클릭 · 카메라 포커스
- 데스크톱·모바일에서 일정 리허설·공유

### 비목표
- 1인칭 거리 / Street View / Unreal급 실사 월드
- 앱 안 턴바이턴 길찾기 (Maps 외부 위임)
- 결제·로그인·예약 연동
- Google Maps API 키 필수 기능

## 5. 핵심 플로우

```
접속 (index.html)
  → 기본: 2일차 또는 마지막 본 일차
  → 디오라마 빌드 + 핀/경로
  → 핀·칩·목록 클릭
       → 상세 패널 (시간·note·via·거리)
       → 카메라 ease to 스팟
  → Maps 길찾기 (선택) → 외부 지도
  → 하단 01–06으로 일차 전환
```

## 7. 데이터

`js/data.js` — 6일 일정 + 위경도 + via(선택) + landmark + `lm`(랜드마크 실좌표)

수동 모형 좌표(`mx`/`mz`, `lmX`/`lmZ`)는 폐기했다. 배치는 전부 `projectDay()` 가 위경도에서 만든다.
디오라마와 미니맵이 같은 함수를 공유하므로 두 그림은 구조적으로 어긋날 수 없다.

| 03 | 대관람차 · 오다이바 |
| 04 | 타워 · 모리 |
| 05·06 | 후지산 |
