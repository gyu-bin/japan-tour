# 프롬프트 · 도쿄 3D 여행 페이지

> 바르셀로나 샘플 프롬프트를 이 여행에 맞춰 다시 쓴 것.
> 아래 블록을 통째로 복사해 쓰면 된다.

---

2026년 10월 17일부터 22일까지의 도쿄 여행을 위한 인터랙티브 웹페이지를 만들어줘.
현지 도착·출국 기준 **5박 6일**이고, 규빈과 규원 두 사람의 일정이야.

핵심은 날짜와 장소를 클릭할 때 해당 위치로 이동하는 3D 지도야. 여행 일정을 눈으로 보면서
쉽게 이해하고, 실제 여행 전에 도시를 둘러보는 경험을 제공해줘.

## 3. 지도와 상호작용

- 날짜 클릭: 그날 전체가 화면에 들어오게 맞춤
- 장소 클릭: 해당 명소로 확대하고 선택 상태 표시
- 번호가 있는 지도 마커와 일정 목록을 서로 연결
- `여기만 보기`: 선택한 장소만 남기고 나머지를 접음
- `전체 보기`: 그날 전체 복귀
- 시간대 전환: `자동 · 새벽 · 아침 · 석양 · 저녁 · 야경 · 심야`.
  `자동`은 일정의 실제 시각을 따라간다 (Day 01은 자정 도착, Day 06은 새벽 일출)
- 확대, 축소, 드래그, 회전, 핀치 지원
- `Maps 길찾기`: 선택한 좌표로 외부 지도 (이동수단에 맞는 모드로)
- 지도 연결선은 방문 순서이며 실제 도로 경로가 아니라는 안내 표시
- 지도 로딩, 오류, 폴백 화면 제공

### 지도 표현 — 여기가 제일 중요하다

**"떠 있는 조각"이 아니라 한 장의 땅 위에 지도가 얹혀야 한다.**

- 스팟 주변 **반경 300~700m의 실제 OSM 데이터**(도로망·물·공원·철도·지하철·역)를
  미리 정적 파일로 구워서 쓴다. 런타임에 Overpass를 호출하지 말 것 —
  여행지에서 모바일 데이터로 열면 느리고 실패한다
- 조각은 **가장자리에서 알파로 사라져** 주변 지형에 스며든다. 섬처럼 뚝 끊기면 안 됨
- 땅의 윤곽은 정원(正圓)이 아니라 **굴곡 있는 해안선**. 그 바깥은 물
- **축척이 두 개라는 걸 숨기지 말 것**
  - 조각 **안** = 실제 지도 비율
  - 조각 **사이** = 방위는 실측, 거리는 압축 — 압축률을 미니맵에 표기
- **방위각은 절대 건드리지 않는다.** 겹치면 반경만 조정
- 60m 안의 스팟은 **떼어놓지 말고 합친다** (같은 건물의 다른 층은 같은 자리가 맞다)
- 기준점은 평균이 아니라 **중앙값** — 멀리 떨어진 스팟 하나가 나머지를 뭉개지 않게
- **미니맵과 3D가 같은 투영 함수를 공유**해서 두 그림이 어긋날 수 없게
- 도로 폭은 **과장**한다 (지도의 표준 표현). 실폭이면 건물 모형 옆에서 실처럼 사라진다
- 조명은 **평평하게**. 그림자 대신 톤 차이로 면을 나눠 일러스트로 읽히게
- 지하철은 반투명 점선(지상 철도는 불투명), 역은 작은 플랫폼 모형, 전철은 노선당 1대
- 역 이름은 **확대했을 때만** — 항상 띄우면 스팟 핀과 싸운다
- 라벨이 겹치면 번호 배지로 줄이고, 그마저 자리가 없으면 감춘다

건물은 **양식화된 모형**이다. 실사 3D 데이터가 아니라는 걸 분명히 하고,
단순한 모형을 실사라고 설명하지 마.

## 5. 구현과 완성도

- **바닐라 ES 모듈 + three.js**로 구현 (빌드 도구 없이 정적 서버만으로 동작).
  React를 쓰고 싶으면 별도로 말해줘 — 지금 구조를 전부 갈아엎게 된다
- 일정 데이터(`js/data.js`)와 화면 코드를 분리. 투영·배치 로직도 데이터 쪽에 두어
  지도와 미니맵이 같은 계산을 공유하게
- 모형·조명·라벨·교통을 각각 별도 모듈로. 한 파일이 1,000줄을 넘지 않게
- 사진과 지도 데이터의 출처·라이선스 표시 (OSM · Kenney CC0 등)
- 키보드 조작, 선택 상태, 모션 감소 설정 지원
- 지도 컨테이너의 너비·높이를 명시하고, 라이브러리 CSS가 덮어써도 영역이 사라지지 않게
- **뷰포트가 0으로 보고되는 경우**(숨겨진 탭·복원 직후)에도 카메라 행렬이 NaN이 되지 않게 방어
- **직교 카메라의 near/far를 넉넉히** — 좁게 잡으면 넓은 바다·지형이 통째로 잘린다
- 개발 서버는 **캐시를 꺼야 한다.** `python3 -m http.server`는 캐시 헤더를 안 보내서
  브라우저가 ES 모듈을 옛 버전으로 물고 있는다
- 실제 브라우저에서 지도 표시, 날짜·장소 클릭, 회전, 시간대 전환, 모바일 레이아웃을
  전부 테스트하고 발견한 오류를 수정

설명이나 디자인 시안만 제시하지 말고, 작동하는 웹페이지를 완성해줘.
